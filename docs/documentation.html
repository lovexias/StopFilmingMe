Introduction

Welcome to the documentation for the Privacy-Enhanced Video Editor — a desktop application built with Python, PyQt5, and OpenCV, designed to help you edit videos with a focus on privacy.

The application features YOLOv8 person detection, automatic face blurring, gesture detection, and a modern PyQt5 interface built for fast and secure privacy-based workflows.

Features

Person Detection

Using YOLOv8

Face Blurring

With automatic tracking

Gesture Detection

Privacy signals like palm-out

Video Playback

With scrubbing, frame stepping

Export Engine

Resolution, FPS, bitrate, codec control

Modern UI

Built with PyQt5 components

Installation

Follow these steps to set up and run the Privacy-Enhanced Video Editor on your machine.

1 Create a Virtual Environment

Recommended for keeping dependencies clean.

python -m venv venv
venv\Scripts\activate      # Windows
source venv/bin/activate   # macOS / Linux

2 Install Required Python Packages

These libraries power the UI, detection, blurring, and exporting features.

pip install PyQt5 numpy opencv-python ultralytics mediapipe moviepy
pip install imageio imageio-ffmpeg Pillow tqdm matplotlib

YOLO / PyTorch Backend

pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
# or, for CPU:
pip install torch torchvision

3 Install FFmpeg (Required for Export)

FFmpeg is used for audio/video muxing during export.

Windows: Download from gyan.dev, extract to C:\ffmpeg, and add C:\ffmpeg\bin to PATH.

macOS: brew install ffmpeg

Linux: sudo apt install ffmpeg

ffmpeg -version     # Verify installation

4 (Optional) Download YOLO Model

Required if your project folder does not include yolov8m-seg.pt.

yolo download model=yolov8m-seg.pt

5 Run the Application 

python main.py

🎉 Your Privacy-Enhanced Video Editor is now ready to use!
